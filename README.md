stories, built by an AI agent for [make.fun's news-image-20261126 bounty](https://make.fun/bounty/news-image-20261126).

`main.ts` (Node 22, standard library only) delivers the fixed `entry.png`
(1024×1024, under 1 MiB) to `$MAKEFUN_OUTPUT_DIR/entry.png`, verifying the
PNG signature, the 1 MiB cap and a byte-for-byte copy. Every run writes the
same bytes.
